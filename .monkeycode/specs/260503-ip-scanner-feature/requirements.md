# 需求文档 - IP扫描功能

## 文档信息
- 创建日期: 2026-05-03
- 项目名称: ADBRemoteATV
- 功能名称: IP扫描功能
- 版本: 1.0

## 功能概述

在IP地址输入窗口旁增加一个IP搜索按钮，用户按下按钮可以扫描局域网内开启ADB服务(端口5555)的设备，点击扫描结果后可以直接连接，无需手动输入IP地址。

## 用户场景

### 场景1：IP地址变化后重新连接
- 用户之前连接过智能电视，但电视的IP地址因路由器重启而改变
- 用户需要快速找到新IP并重新连接
- 传统方式：需要手动输入IP地址，容易出错
- 新功能：点击扫描按钮，自动发现可连接设备

### 场景2：多设备环境
- 用户局域网内有多台智能电视或设备
- 用户不确定哪台设备的IP地址是哪个
- 传统方式：需要逐个尝试IP地址
- 新功能：扫描显示所有可用设备，一目了然

## 功能需求（使用EARS模式）

### REQ-FUNC-001：扫描按钮展示
- **系统应当**在IP地址输入框旁边显示一个IP扫描按钮。
- **扫描按钮应当**使用清晰的图标（如搜索图标）和文字提示"扫描"。

### REQ-FUNC-002：IP扫描执行
- **当用户点击扫描按钮时**，**系统应当**启动局域网IP扫描。
- **扫描过程应当**在后台线程执行，不阻塞主UI线程。
- **系统应当**在扫描期间显示扫描进度提示。

### REQ-FUNC-003：扫描范围和策略
- **系统应当**扫描当前设备所在的局域网网段。
- **扫描范围应当**限定为IPv4地址段（如192.168.1.x）。
- **系统应当**检查每个IP地址的5555端口是否开放（ADB默认端口）。
- **扫描过程应当**使用多线程并发检测以提高扫描速度。

### REQ-FUNC-004：扫描结果显示
- **当扫描完成后**，**系统应当**在弹窗中显示所有检测到的ADB设备列表。
- **设备列表应当**包含IP地址、设备名称（如果可获取）、连接状态。
- **设备列表应当**按照发现顺序或IP地址排序。
- **如果未发现任何设备**，**系统应当**显示友好提示信息。

### REQ-FUNC-005：设备连接
- **当用户点击设备列表中的设备时**，**系统应当**自动填充IP地址和端口（5555）到输入框。
- **如果用户点击设备时**，对话框应当关闭，返回到连接界面。
- **用户可以**选择直接连接或修改别名后连接。

### REQ-FUNC-006：扫描控制
- **系统应当**允许用户在扫描过程中取消扫描。
- **当用户取消扫描时**，**系统应当**停止所有后台扫描任务。
- **扫描超时时间应当**设置为30秒，避免长时间等待。

### REQ-FUNC-007：权限要求
- **系统应当**拥有ACCESS_WIFI_STATE权限以获取当前网络信息。
- **系统应当**拥有INTERNET权限以进行网络扫描。

### REQ-UI-001：扫描按钮布局
- **扫描按钮应当**放置在IP输入框的右侧。
- **按钮尺寸应当**与输入框高度匹配。
- **按钮样式应当**与其他UI元素保持一致。

### REQ-UI-002：扫描结果弹窗
- **扫描结果应当在独立的Dialog中显示**。
- **弹窗应当**包含设备列表RecyclerView。
- **弹窗标题应当**显示"发现X台设备"。
- **弹窗应当**包含"取消"按钮用于关闭。

### REQ-PERF-001：扫描性能
- **扫描254个IP地址（完整C类网段）的时间应当**不超过30秒。
- **系统应当**使用线程池并发扫描，建议并发数为10-20个线程。

### REQ-PERF-002：内存管理
- **扫描过程中**，**系统应当**及时释放不再使用的Socket连接。
- **扫描结果列表应当**限制最多显示20个设备，避免内存溢出。

## 非功能性需求

### NFR-SEC-001：网络安全
- **系统应当**仅扫描局域网网段，不扫描公网地址。
- **系统应当**不保存扫描结果中的设备敏感信息。

### NFR-UX-001：用户体验
- **扫描过程应当**显示进度指示器（如ProgressBar）。
- **扫描超时后**，**系统应当**显示友好提示并允许用户重试。
- **发现设备时**，**系统应当**提供视觉反馈（如震动或提示音）。

### NFR-COMP-001：兼容性
- **功能应当**兼容Android API 24及以上版本（minSdk 24）。
- **功能应当**在WiFi网络环境下正常工作。

## 验收标准

### AC-001：扫描按钮显示
- 在IP输入框旁边成功显示"扫描"按钮
- 按钮图标和文字清晰可见
- 按钮点击响应正常

### AC-002：IP扫描功能
- 点击扫描按钮后开始扫描
- 扫描过程中显示进度提示
- 扫描在30秒内完成

### AC-003：设备发现
- 能够发现局域网内开启ADB端口的设备
- 设备列表正确显示IP地址
- 设备列表能够显示多个设备

### AC-004：设备连接
- 点击设备后正确填充IP地址到输入框
- 点击设备后正确填充端口号5555
- 能够正常连接到扫描到的设备

### AC-005：边界条件处理
- 网络断开时显示友好提示
- 扫描无结果时显示"未发现设备"提示
- 扫描过程中点击取消能够正常停止

## 约束和限制

- 扫描功能仅在WiFi网络环境下可用
- 扫描范围限制在本地网段
- 每次扫描最多显示20个设备
- 扫描超时时间为30秒

## 风险和注意事项

- 扫描过程可能被防火墙阻止，需要提示用户
- 大规模网络扫描可能影响网络性能，需要控制并发数
- 某些设备可能禁用了ADB调试，需要提示用户检查设置
